# DIAGNOSTYS™ Quiz Specification

Este repositório consolida todo o desenho lógico do **Diagnostys™ Quiz – Versão Sobrevivência**.
Ele serve como fonte única da verdade para quem for implementar motores de perguntas,
regras de pontuação, relatórios gratuitos e relatórios pagos do diagnóstico operacional.

- `data/quiz-structure.json` descreve cada pergunta, condições de exibição, pesos e
  modificadores.
- `docs/reports-layout.md` apresenta os layouts finais do relatório gratuito e do
  relatório pago (R$ 97), com blocos e textos sugeridos.

> ✅ Nenhum código-fonte de aplicação está aqui ainda. Este repositório documenta o
> comportamento esperado para que equipes de produto, engenharia, design e conteúdo
> possam trabalhar de forma alinhada.
